# Development phases

## Phase 1 — Data foundation
Inspect the transaction, accounts, and laundering-pattern files; document schemas; clean data; create reusable preprocessing; and perform exploratory analysis.

## Phase 2 — ML models
Compare Logistic Regression, Random Forest, and XGBoost using fraud/AML-aware metrics.

## Phase 3 — Streaming
Simulate transactions with Kafka and process them in real time.

## Phase 4 — Backend
Add FastAPI and PostgreSQL.

## Phase 5 — Graph
Load account and transaction relationships into Neo4j.

## Phase 6 — Agents
Build the LangGraph investigation workflow.

## Phase 7 — Evidence tools
Connect agents only to retrieved database, graph, history, and model tools.

## Phase 8 — Explainability
Add SHAP explanations for individual predictions.

## Phase 9 — Dashboard
Build the React investigation and monitoring interface.

## Phase 10 — Integration
Test the complete human-in-the-loop workflow.
