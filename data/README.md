# Data directory

Raw Kaggle files belong in `data/raw/` and generated datasets belong in `data/processed/`.

The raw dataset is intentionally excluded from GitHub because the transaction file is large. Download the IBM Transactions for Anti-Money Laundering dataset from its original Kaggle source and place these files in `data/raw/`:

- `HI-Small_Trans.csv`
- `HI-Small_accounts.csv`
- `HI-Small_Patterns.txt`

Do not save or convert these CSV files using Excel. Preserve the original files.
